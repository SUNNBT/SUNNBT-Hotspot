SUNNBT Hotspot V1（Windows 图形界面版）

快速开始
1. 将 SUNNBT_Hotspot_GUI 文件夹完整复制或解压到目标 Windows 电脑上的任意可访问位置。
2. 双击 SUNNBT_Hotspot_GUI.exe。
3. 在 Windows 用户账户控制（UAC）提示中选择“是”。
4. 在窗口中点击“启动热点”或“停止热点”。启动并确认成功后，会自动打开热点设备管理程序。

运行与兼容性
- 本发行包已包含程序运行所需的 Python 运行库、程序依赖和背景视频；无需另外安装 Python 或下载依赖。发行文件夹可以整体复制或移动，程序不依赖开发机上的绝对路径。
- 文件按用途分类：背景视频和预览图位于 `Videos`，说明文档位于 `Docs`，设备管理程序位于 `Tools\client_manager`，运行库和解码组件位于 `_internal`，日志写入 `Logs`。
- 开发者可在项目根目录运行 `YUANMA\build_portable_release.ps1`，生成 `BUILD\SUNNBT_Hotspot_GUI` 文件夹发行包。
- 请保留发行目录中的 EXE 以及 `_internal`、`Videos`、`Tools` 等文件夹，不要只复制 EXE，也不要删除或改动发行文件。日志目录不可写时，日志会回退到当前 Windows 用户的 `%LOCALAPPDATA%\SUNNBT_Hotspot\Logs`。
- 适用于 64 位 Windows 10/11。需要可用的 Internet 连接，以及支持 Windows 移动热点的无线网卡和驱动。
- 热点能力由 Windows、无线网卡及其驱动提供；不支持移动热点的电脑无法通过本程序创建热点。本程序不支持 macOS、Linux 或 32 位 Windows。
- 首次启动和启动热点时，Windows 可能会显示管理员权限（UAC）提示。

功能说明
- 热点名称：SUNNBT111
- 热点密码：SUNNBT111
- “启动成功后自动关闭”默认勾选：热点启动成功后，窗口显示 3 秒再关闭，热点继续运行。取消勾选可保持窗口打开。
- 自动关闭选项保存在当前 Windows 用户的 %LOCALAPPDATA%\SUNNBT_Hotspot\settings.json。
- 热点主程序的日志为 `Logs\start_hotspot.log`，设备管理日志为 `Logs\client_manager.log`；发行目录不可写时会保存到用户数据目录。
- 背景视频和首帧预览图位于 `Videos`，解码组件位于 `_internal`；创建 GUI 窗口前就会启动后台视频解码，窗口出现时先显示预载的首帧预览，再自动切换为动态背景，不等待视频解码完成。
- 程序使用 Windows 自带的 Windows PowerShell、网络适配器和移动热点功能。
- 启动阶段会枚举包含隐藏设备在内的网卡，并逐个确认禁用的网卡已启用；设备不存在、驱动故障或权限/策略拒绝时，日志会列出失败项。
- 个别网卡启用失败或网卡枚举遇到问题时会记录警告并继续尝试启动热点；热点本身无法配置或启动时仍会报告致命错误。
- 设备管理程序显示 Windows 移动热点返回的在线设备名称和 MAC 地址，并显示 Wi-Fi Direct 虚拟网卡的总上传/下载速度。
- “停止热点（断开全部设备）”会关闭整个热点并断开所有客户端。
- Windows 10 移动热点 API 不提供对单台设备踢出/封禁、限速或设备级实时流量计数的接口。因此程序不伪造这些功能；设备表中的单设备速度会明确标为不可用。需要这些能力时，应使用支持客户端隔离/限速的专用路由器或热点软件。

注意：由于操作系统、无线网卡和驱动存在差异，无法保证在所有电脑上都能启用 Windows 移动热点。
